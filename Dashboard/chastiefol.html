Data flow

1
Data Feed → Analysis Engine → Signal Generation
Multi-provider OHLCV data consumed by the analysis engine. Technical indicators and SMC patterns computed. Confluence score generated per bar.
2
Signal → Risk Check (DrawdownGuard + PositionSizer)
Signals passing 55/100 confidence gate enter the risk pipeline. Drawdown status checked, lot size calculated, entry price validated against live FIX price (<1% deviation allowed).
3
Risk Check → Execution (MCP / FIX / Paper)
Approved orders routed to configured execution method. FIX orders submitted as 35=D (Market) with SL/TP set via 35=AM (ModifyPosition) post-fill. Numeric symbol IDs required for FIX.
4
Execution → Trade Manager (Trailing / Breakeven / Partial TP)
Open positions monitored every tick. Breakeven activated at 1:1 R:R, 50% partial close executed, trailing SL follows ATR-based formula until full close.
5
Events → Telegram Notifier
Every lifecycle event (signal, fill, close, drawdown breach, error) triggers a formatted Telegram message to the configured chat ID.

SETUP GUIDE

Getting started

From zero to a live autonomous gold trading agent in 5 steps.

Prerequisites

🐍

Python 3.10+

Required for asyncio features

📈

cTrader Account

Demo or live account

🔑

API Keys

TwelveData / AlphaVantage / GoldAPI (optional)

1

Clone the repository

Get the source code from GitHub.

git clone https://github.com/fataakromulmuttaqin/Chastiefol cd Chastiefol
2

Install dependencies

Install all required Python packages.

pip install -r requirements.txt
3

Configure environment

Copy the example config and fill in your credentials. At minimum, configure your execution method and broker credentials.

cp .env.example .env nano .env # or vim, or your preferred editor

Key settings to configure: EXECUTION_METHOD, FIX_SENDER_COMP_ID, FIX_PASSWORD, TELEGRAM_BOT_TOKEN

4

cTrader setup

For MCP: Obtain your Bearer access token from the cTrader dashboard. Set CTRADER_ACCESS_TOKEN — the value must include the "Bearer " prefix.

For FIX: Use your demo credentials in format demo.ctrader.XXXXXX and your FIX password. Set FIX_SYMBOL_MAP={"XAUUSD":"41"} — numeric IDs are required for FIX.

5

Launch the agent

Start Chastiefol. It will connect to broker, initialize data feeds, and begin scanning.

python chastiefol_main.py

✓ You should receive a 🟢 CHASTIEFOL ONLINE Telegram message on successful startup.

TradingView Webhook Integration

1

Create a TradingView alert

On any chart or strategy, create a new alert with "Webhook URL" as the notification method.

2

https://your-domain.com/webhook

TROUBLESHOOTING

Common issues

Solutions for the most frequently encountered issues.

Order rejected: "Symbol must be numeric"
Using string symbol name instead of numeric ID in FIX
→ Set FIX_SYMBOL_MAP={"XAUUSD":"41"} in .env · cTrader FIX requires numeric IDs
FIX
Order rejected: "Invalid MsgType"
Attempting to include SL/TP in the initial 35=D order message
→ Use modify_position() (35=AM) to set SL/TP after order fill, not in the initial order
FIX
MARKET_CLOSED error
Attempting to trade during weekend or holiday hours
→ Wait for market open (Sunday 22:00 UTC for gold markets)
BROKER
Price validation failed
Stale data feed prices causing >1% deviation from live FIX price
→ FIX price is now primary fallback for validation · Check data feed connectivity
DATA
TwelveData rate limited
Daily 800 credit limit reached on free plan
→ Wait for 00:00 UTC reset · AlphaVantage fallback should activate automatically · Consider upgrading
DATA
MCP 401 Unauthorized
Missing "Bearer " prefix in access token configuration
→ Token must be formatted as f"Bearer {your_token}" — ensure the "Bearer " prefix is included
MCP
Telegram messages not received
Incorrect bot token or chat ID
→ Verify TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID · Ensure you have started a conversation with the bot
TELEGRAM
Confidence score always below threshold
Insufficient confluence factors or wrong timeframe
→ Ensure data feed is returning full OHLCV history · Verify timeframe setting · Lower MIN_CONFIDENCE temporarily to debug
