# Chastiefol — Pine Script Strategy

## Quick Start

1. Open TradingView → Pine Editor
2. Copy-paste `chastiefol_xauusd_strategy.pine`
3. Add to chart (XAUUSD, timeframe H1 recommended)
4. Set up Alert → Webhook URL pointing to your Chastiefol agent

## Strategy Logic

### Primary Signal (PSAR + EMA)

| Signal | Conditions |
|--------|------------|
| **BUY** | PSAR flips below price + Price > EMA20 > EMA50 > EMA100 > EMA200 |
| **SELL** | PSAR flips above price + Price < EMA20 < EMA50 < EMA100 < EMA200 |
| **CLOSE** | PSAR flips opposite direction OR price crosses EMA200 |

### Confirmation Indicators (Optional)

| Indicator | Bullish Confirm | Bearish Confirm |
|-----------|----------------|-----------------|
| RSI(14) | 50 < RSI < 70 | 30 < RSI < 50 |
| MACD | MACD > Signal & Hist > 0 | MACD < Signal & Hist < 0 |
| Bollinger | Price > Middle Band | Price < Middle Band |
| Volume | Above 1.2x average | Above 1.2x average |

### Confluence Scoring (0–7)

Each confirming factor adds +1:
1. PSAR direction
2. EMA perfect order alignment
3. Price above/below all EMAs
4. RSI confirmation
5. MACD confirmation
6. Bollinger Bands confirmation
7. Volume confirmation

**Minimum default: 3/7 for signal generation.**

## Risk Management

- **Stop Loss**: ATR(14) × 1.5 multiplier
- **Take Profit**: SL × 2.0 (Risk:Reward)
- **Trailing Stop**: PSAR-based (optional)

## Alert Setup (TradingView → Chastiefol)

1. Right-click chart → "Add Alert"
2. Condition: Select "Chastiefol XAUUSD [PSAR + EMA]"
3. Webhook URL: `http://YOUR_SERVER:8080/webhook`
4. Add Header: `X-Webhook-Secret: your_secret_key`
5. Message: Leave blank (auto-generated by script)
